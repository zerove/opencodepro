# 语言开发规范库 (Language Spec Library)

本目录包含了针对不同编程语言的 AI 协同开发标准。这些规范旨在将“通用 AI 技巧”转化为“语言特定”的工程实践，确保 AI 生成的代码不仅能运行，而且符合该语言的最佳实践（Best Practices）。

## 📂 规范索引

### 核心开发语言
- [**Python 规范**](python.md)：侧重于类型提示、异步 IO 和 Pythonic 风格。
- [**TypeScript/JS 规范**](typescript.md)：侧重于强类型约束、组件原子化和异步流控制。
- [**Rust 规范**](rust.md)：侧重于所有权管理、生命周期显式化和零成本抽象。
- [**Java 规范**](java.md)：侧重于现代语法 (Java 17+)、Spring 惯例和企业级健壮性。
- [**Go 规范**](go.md)：侧重于显式错误处理、并发原语和简约风格。
- [**C# 规范**](csharp.md)：侧重于现代 .NET 语法、LINQ 优化和异步模式。
- [**Kotlin 规范**](kotlin.md)：侧重于空安全、协程调度和函数式简洁性。
- [**Swift 规范**](swift.md)：侧重于值类型优先、结构化并发和声明式 UI。

### 系统与底层
- [**C++ 规范**](cpp.md)：侧重于现代标准 (C++17/20)、RAII 和内存所有权审计。
- [**Shell/Bash 规范**](shell.md)：侧重于防御性编程、变量安全和幂等性。

### 数据语言
- [**SQL 规范**](sql.md)：侧重于 Schema 驱动生成、执行计划预判和性能优化。

## 🛠️ 如何使用这些规范？

### 1. 作为 System Prompt 的补充
在与 AI 协作时，将对应语言规范中的 **“定向提示策略”** 部分直接加入到 System Prompt 中。
*例如*：在开发 Rust 项目时，告知 AI：“请遵循 `rust.md` 中的借用检查预审模式，在编写逻辑前先分析所有权流转。”

### 2. 作为交付验收标准
在 AI 生成代码后，对照 **“AI 质量验收清单”** 进行逐项审计。如果清单中有一项未达成，则要求 AI 重新修正。

### 3. 引导 AI 学习
当 AI 给出不符合规范的代码时，直接将规范中的相关条款发送给它：
*“你的实现违反了 [Python AI Spec] 中的‘类型提示’要求，请重新使用 typing 模块进行定义。”*
