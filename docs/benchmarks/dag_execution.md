# 认知引擎性能基准：DAG 执行模块

## 概述
本报告记录了 `sisyphus-core` 中 DAG 执行模块的性能基准数据，作为系统稳定性的量化证据。

## 测试环境
- 工具：`criterion`
- 测试模块：`sisyphus-core::dag_execution`
- 节点规模：20 节点任务图谱

## 性能数据 (2026-11-20)
- **平均执行延迟**: 3.25 ms
- **95% 置信区间**: [3.17 ms, 3.33 ms]
- **标准差**: 0.28 ms

## 结论
在 20 节点规模下，系统执行开销稳定，满足认知循环的实时性要求。
