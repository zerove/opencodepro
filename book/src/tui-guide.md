# TUI 指南

Sisyphus 包含基于 ratatui 构建的全功能终端用户界面（Terminal User Interface，TUI）。

## 导航

| 按键 | 操作 |
|-----|--------|
| `Ctrl+K` | 打开命令面板 |
| `Ctrl+L` | 会话列表 |
| `Ctrl+M` | 模型列表 |
| `Ctrl+A` | 代理列表 |
| `Ctrl+N` | 新建会话 |
| `Ctrl+H` | 返回主页 |
| `Ctrl+Q` | 退出 |
| `F1` | 帮助 |

## 输入编辑

| 按键 | 操作 |
|-----|--------|
| `Home` / `End` | 移至行首/行尾 |
| `Ctrl+U` | 删除到行首 |
| `Ctrl+W` | 向后删除一个单词 |
| `Ctrl+V` | 从剪贴板粘贴 |

## 斜杠命令

在输入框开头输入 `/` 触发斜杠命令补全弹窗。

可用命令：

| 命令 | 说明 |
|---------|-------------|
| `/help` | 显示按键绑定与帮助 |
| `/exit` | 退出 Sisyphus |
| `/clear` | 清空日志 |
| `/theme` | 切换深色/浅色主题 |
| `/sessions` | 切换或管理会话 |
| `/new` | 创建新会话 |
| `/model` | 切换 AI 模型 |
| `/agent` | 切换代理 |
| `/dev` | 运行自主开发代理 |
| `/todos` | 管理待办列表 |
| `/lsp` | 查看 LSP 诊断 |
| `/sop` | 列出并执行 SOP |
| `/skills` | 浏览并安装技能 |
| `/roadmap` | 查看项目路线图 |
| `/bridge` | 检查 bridge 健康状态 |
| `/home` | 返回主页屏幕 |
| `/search` | 在会话中搜索消息 |

### 导航

- `Up` / `Down` - 在补全列表中导航
- `Tab` / `Enter` - 接受选中的补全
- `Esc` - 关闭补全弹窗

## @文件引用

在输入中使用 `@` 前缀引用文件：

```
Look at @src/main.rs and @lib.rs
```

文件内容将自动展开，行数上限为 200 行。

## 会话功能

- **分叉**：从任意会话创建分支
- **撤销**：回退最后一条消息
- **重命名**：更改会话名称
- **压缩**：总结旧消息以节省 token
- **检查点**：保存/恢复会话状态
- **导出**：导出为 JSON 或 HTML
- **导入**：从 JSON 导入

## 搜索

在会话中按 `/search` 激活搜索模式。用 `n`（下一个）与 `p`（上一个）导航匹配项。
